# DeebTracker

Logs everything that happens to your characters (quests, XP, kills, levels, zones, deaths, gold) with timestamps, for WoW Forever route data. /dt for status.

Part of [Deeb's Addon Emporium](https://github.com/deeb-addon-emporium/emporium). **WoW Forever only**
(the `_classic_beta_` client, interface 16001).

## Install with WowUp

1. WowUp → Settings → Addon providers → enable **GitHub**.
2. Get Addons → Install from URL → paste `https://github.com/deeb-addon-emporium/DeebTracker`.
3. Updates show up in WowUp like any other addon.

## Install by hand

Download the zip from the latest release and drop the `DeebTracker` folder into
`World of Warcraft/_classic_beta_/Interface/AddOns/`.

Current version: 1.1
